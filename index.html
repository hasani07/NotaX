Atur Spreadsheet Project

Sambungkan project ini ke spreadsheet Google-nya sendiri, biar tiap nota yang kamu simpan otomatis nambah baris ke sana.

📋 Cara dapetin Apps Script Web App URL (sekali per spreadsheet)
  1. Buka spreadsheet project ini di Google Sheets.
  2. Klik menu Extensions → Apps Script.
  3. Hapus kode bawaan, lalu tempel kode di bawah ini.
  4. Simpan (Ctrl+S / ikon disket), boleh dikasih nama misalnya "NotaX Sync".
  5. Klik Deploy → New deployment. Pilih tipe Web app.
  6. Execute as: Me. Who has access: Anyone. Klik Deploy.
  7. Google akan minta izin akses — klik lanjutkan (kalau muncul peringatan "unsafe", klik Advanced → Go to (nama script) karena ini script buatan kamu sendiri).
  8. Salin Web app URL yang muncul, tempel ke kolom "Apps Script Web App URL" di atas.
  9. Penting: jangan hapus atau ubah isi kolom ID di spreadsheet — kolom itu dipakai NotaX buat tahu baris mana yang cocok dengan catatan yang mana. Ubah/hapus kolom lain (Beli Apa, Total, dst) aman dan akan ke-sync ke NotaX.
  10. Sudah pernah deploy sebelumnya (kode versi lama)? Update kode script-nya ke versi ini lagi, lalu Deploy → Manage deployments → klik ikon pensil di deployment yang ada → di "Version" pilih "New version" → klik Deploy. Cara ini bikin URL-nya tetap sama, jadi kamu tidak perlu ganti URL di NotaX lagi.
  11. Script ini juga otomatis bikin tab "Ringkasan" berisi total belanja per "Pakai Uang" (mis. total Uang Hasani, total Uang PT) + total semuanya, yang selalu update tiap ada nota baru masuk.
  12. Baru: kalau nota-nya ada foto bukti, sekarang otomatis di-upload ke folder Google Drive (satu folder sama dengan spreadsheet-nya), dan link-nya nempel di kolom "Link Foto Nota". Saat proses deploy nanti, Google mungkin minta izin tambahan ke Google Drive — klik izinkan, itu dipakai untuk simpan foto-nya.
  13. Foto dikirim bertahap (dipecah jadi beberapa bagian kecil), jadi proses simpan nota yang ada fotonya makan waktu beberapa detik lebih lama dari nota tanpa foto. Ini normal.
  14. Penting: pastikan di Deploy → Manage deployments → Edit, kolom "Execute as" diisi "Me" dan "Who has access" diisi "Anyone" (bukan "Anyone with Google account") — kalau salah satu ini beda, permintaan dari NotaX akan ditolak.
